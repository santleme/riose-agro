# Rural native pasture material · v1

## Use
Surface-color source for the offline V5 elevation mesh. This is a material texture, not a placed scene or ground tile; the mesh determines world geometry and height.

## Prompt
Create a square seamless repeatable BASE MATERIAL texture only, for a detailed 2.5D isometric Brazilian ranch game environment. Treat the existing farm screenshot as subject and established palette; the rich pixel-art city screenshot is only a quality reference for crisp environmental rendering. No scene, buildings, fences, animals, roads, outlines, perspective, horizon, tile boundaries, or lighting gradient. Orthographic material texture viewed straight down, seamless on all four edges. Medium-density pixel-art brushwork: warm sunlit pasture greens, clustered short native grass, restrained straw-colored seed heads, occasional earth scuffs, subtly mottled patches at varied organic scales, high local detail without noisy speckle. Broad green mass stays readable; avoid obvious repeated motifs. Natural Brazilian cerrado pasture, lush but not neon. 1024x1024.
