# Scientific product roadmap

1. Preserve the current deterministic JavaScript engine and native/WASM parity while simplifying the interface around experiments.
2. Keep assumptions, model status, units, source provenance, and data eligibility visible in every comparison and export.
3. Expand scientific validation only with independent datasets, predeclared evaluation protocols, and versioned evidence.
4. Profile engine execution, snapshot cost, worker transfer, and history storage separately; optimize measured bottlenecks without changing equations.
5. Keep observational data, simulated outputs, and reviewed post-decision outcomes in distinct contracts.

Do not claim predictive validity or causal effects until their corresponding evidence gates pass. Preserve older snapshots and archives through explicit input adapters.
