# Próximas prioridades do motor científico

1. Manter execução JS/Rust/WASM determinística e validar snapshots históricos após cada mudança de contrato.
2. Tornar explícitos o domínio, as entradas requeridas, unidades e limitações de cada modelo.
3. Priorizar avaliações externas independentes e análise de erro antes de adicionar novas alegações preditivas.
4. Preservar exportação de resultados, manifests, histórico de execução e reprodutibilidade local.
5. Usar os benchmarks computacionais existentes para orientar otimizações; não alterar fórmulas sem revisão científica versionada.

A interface não deve converter resultados demonstrativos em recomendação, previsão validada ou efeito causal.
