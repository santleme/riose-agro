# Perea generative baselines v1 — development folds

Generated by `npm run evaluate:perea-behavior-baselines` under the frozen protocol in [`07-baseline-preregistration-v1.md`](../../specs/riose-behavioral-agents/07-baseline-preregistration-v1.md). Per-animal metrics, source/protocol/implementation digests, and fold membership are in [`perea-generative-baselines-v1.json`](perea-generative-baselines-v1.json).

## Frozen split and execution

- Five development folds, each with 16 training and 4 held-out animals (one per breed); all windows for an animal stay in one fold.
- Four animals are reserved for a later confirmatory comparison. The evaluator does not calculate or report scores for those animals.
- 20 seeded generated replicas per observed test window for IID, one-state persistence, and first-order Markov baselines.
- Sequence boundaries use exact-minute contiguity. No transition crosses a gap. Generator input is training-derived parameters, output length and deterministic seed; it receives no test labels or motion index.
- Tests cover frozen split membership, animal disjointness, gap handling, censoring, deterministic bounded output, ontology, and maximum transition penalty when a generator fails to represent an observed source state.

## Development results

| Baseline | Animal-macro class-composition MAE | Animal-macro transition row TV | Complete annotated-run median absolute error (min) | Single-class replicate windows |
| --- | ---: | ---: | ---: | ---: |
| IID | 0.3532 | 0.8178 | 3.52 | 43.8% |
| Persistence | 0.3676 | 0.7544 | unavailable (no interior runs) | 100.0% |
| First-order Markov | 0.3600 | 0.7528 | 3.57 | 47.5% |

Lower errors are better. Transition TV compares supported (at least 20 training transitions) source-state rows present in the observed held-out window; if the generator emits no row for an observed source state, that row receives maximum distance 1.0. Window support and per-animal values are in the JSON.

## Interpretation and limits

These diagnostics do not establish valid cattle behavior generation. Scores are from 20 development animals drawn from the same source, not independent external ranches. The Markov baseline improves transition TV over persistence by only 0.0015 and is worse than IID; it does not meet the frozen future semi-Markov selection threshold against both simple baselines. Composition errors are similar. Persistence is structurally degenerate by design. Annotated runs may be prolonged by the source's sub-30-second carry-forward rule. No confidence intervals, physiological outcomes, or FarmEngine changes are inferred. No model is promoted or enabled by default.
