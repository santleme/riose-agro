# Open ADG and pasture biomass candidates: audit note

Audit date: 2026-10-13. This is a source/readiness audit only; no model was fit.

| Candidate | Public files and license | Population, outcomes, units, grain, groups | Decision |
| Dryad mob/rotational pasture biomass, [10.5061/dryad.79cnp5ht4](https://doi.org/10.5061/dryad.79cnp5ht4) | Version 6 ZIP is openly downloadable without credentials, 115,041 bytes; internal XLSX and README checksums match the Dryad API. CC0 1.0. | Cool-season grass-legume pasture under mob and rotational grazing in the northeastern US, 2015–2018. Source has 623 nonmissing per-harvest pre-grazing forage mass (PGFM) values labelled kg/ha from 640 slots; 17 target values are missing. Mean pre-grazing sward height is available at paddock/replicate level, not per quadrat. Processing aggregates biomass quadrats to treatment × replicate × year × harvest (64 records, 8 repeated paddocks) to align with the height grain. | **CONDITIONAL for a distinct external biomass evaluation.** It is independent of the Brazilian Mendeley cohort and may provide a group-held-out external check after review of the documented aggregation and target definitions. Keep repeated observations from each of eight paddocks together. It provides no animal DMI or ADG. |
|---|---|---|---|
| Rothamsted legacy DOI [10.23637/rothamsted.991v9](https://doi.org/10.23637/rothamsted.991v9) | The legacy CKAN page lists CSV/datapackage resources but also says the dataset is private. Repository page now identifies a newer superseding DOI, [10.23637/rothamsted.00033688](https://repository.rothamsted.ac.uk/id/eprint/33688/), with public direct downloads under CC BY 4.0. That exact current snapshot is already local and audited in `data/rothamsted/`. | Young dairy × beef cross steers at North Wyke, 2018–2025; no mature cows. The animal-period CSV has 2,362 rows, 248 official ear tags, six repeated plots (C1–C3 set-stocked, T1–T3 cell-grazed), year/cohort/grazing-period IDs, start/end weights in kg and DLWG computed from the two weights and elapsed days (kg/day; source datapackage labels DLWG units incorrectly as kg). The paired weekly herbage file has 1,210 plot/date records, DM_HM in kg DM/ha, estimated from rising-plate compressed sward height. | **Legacy version: CONDITIONAL / superseded; do not treat as a new source.** Current version is already usable for a separate young-cattle ADG or pasture-herbage-mass module, with animal/plot/cohort grouping. ADG is derived from its own weight endpoints, and the same six plots recur across years; this is not independent mature-cow DMI or full-engine validation. |
| Teagasc AYAF PGSH plot trial, [DOI 10.82253/85FG-J232](https://doi.org/10.82253/85FG-J232) | Official Teagasc record links an XLSX and README; direct public downloads both returned HTTP 200 during this audit. XLSX 444,833 bytes, SHA-256 `fdad452c6499158cc8aeb3dac975ca5a119b21131c671ac7371fd73e22e1972b`; README DOCX 60,292 bytes. README and catalog specify CC BY-NC 4.0, so not eligible for commercial training. | Plot trial at Teagasc Athenry, Galway, 2019-08-26 to 2022-12-01; five sward types (perennial ryegrass alone or with white/red clover, plantain, chicory) × three post-grazing height treatments. No animal-level outcomes or ADG/DMI. XLSX sheets: Herbage Yield (972 data rows), Sward Composition (972), Tiller density (216), Sward Quality (324). Yield records include Year, Season, Rotation, DateCut, Plot (G01 etc.), Block, SampleNo, treatment, and Yield in kg DM/ha. Composition has same plot/date/treatment keys and dry-matter/forage measures; weights kg, content and DM %, yield kg DM/ha. Tiller density has Year/Season/Date/Plot/Block/Treatment and counts per m². Quality has treatment/year/rotation/analysis sample/date; BC, CP, DMD, WSC, described in the README as buffering capacity, crude protein, dry matter digestibility, water-soluble carbohydrates (percent/unit details not supplied for each quality variable). Experimental grouping exists at plot/block/treatment/year/rotation/date, but sheet 4 has no explicit Plot/Block columns. | **CONDITIONAL for noncommercial exploratory forage yield/quality only; INELIGIBLE for commercial training absent commercial permission; INELIGIBLE for ADG/DMI.** It may support a distinct plot-scale herbage yield module after retaining plot/block/treatment/date group structure and documenting incomplete quality units. The README says four years, while the covered dates and XLSX indicate 2019–2022. |

## Source records

- Dryad raw archive and processed cohort: `data/raw/dryad-79cnp5ht4/version-6.zip`, `data/dryad-mob-rotational-biomass/manifest.json`, and `docs/evidence/dryad-mob-rotational-biomass-quality-2026-10.json`. The 623 available sample rows and 64 aligned paddock-time records are produced by `scripts/process_dryad_mob_rotational_biomass.py`; all 17 missing target slots remain absent.
