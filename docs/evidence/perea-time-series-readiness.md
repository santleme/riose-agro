# Perea v2 timestamped sequence readiness

Generated by `python3 scripts/science/source-audits/audit_perea_time_series_readiness.py` from the committed source file. The machine-readable detail, including per-window coverage and per-class observed label-run distributions, is in [`perea-time-series-readiness.json`](perea-time-series-readiness.json).

## Result

- 9,222 published rows and 24 animal identities; 8,918 unique animal-minute keys.
- 290 repeated animal-minute keys (304 excess rows); 54 keys contain contradictory labels. The existing classifier policy excludes all rows at those conflicting keys, collapses unambiguous repeated keys using mean motion index, and yields 8,864 analysis observations.
- This produces 1,305 operational contiguous windows. A window means exact one-minute adjacency after preprocessing; it is not claimed to be a source-defined recording session. Any missing minute, timestamp gap, or excluded contradictory minute ends a window.
- There are zero windows with at least 1,440 consecutive eligible minute observations. Full-day budgets and circadian metrics are unsupported by this source sample.
- Observed runs count annotated minute labels. The README says labels for behaviors under 30 seconds may use the previous annotation. Run lengths therefore are not unbiased biological bout-duration estimates. Runs touching window boundaries are marked censored.
- Source timestamps are labeled Mountain Time but carry no per-row UTC offset or daylight-saving fold. The audit preserves local wall-clock timestamps and does not convert to UTC.
- The source audit records CC BY 4.0 and the Figshare v2 DOI. This work records both MD5 and SHA-256 of the local CSV; it does not perform a fresh upstream license review.

## Compatibility and scope

Tests compare the canonical observations, row order, duplicate handling, and analysis-row count against `scripts/evaluate_perea_behavior_grouped.py::read_observations`. No model is fitted. Motion index is an observed sensor feature, and behavior labels remain distinct from FarmEngine actions. The report supports internal exploratory sequence work only; it does not establish engine validity, physiological effects, ADG, DMI, external-site validity, or permission to promote an experimental behavior model.
