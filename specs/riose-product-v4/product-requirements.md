# Product V4 requirements

V4 adds a decision-analysis layer to the Product V3 scenario lab at `scenario-lab.html`. Existing Product V2, V3, and `experiments.html` contracts remain readable.

| ID | User-visible behavior | Inputs → outputs | Dependencies | Failure states | Acceptance | Scientific constraint | Status |
|---|---|---|---|---|---|---|---|
| PRD-001 | Compare a baseline with multiple alternatives side by side. | Reviewed scenario-set manifest → actual per-arm outputs. | P3-002/003. | Invalid arms, unsupported units, over-budget run. | Existing V3 E2E and replay checks. | Direct comparison only for same model/domain/unit/checkpoint; no causal interpretation. | DONE — reused |
| PRD-002 | Sweep one eligible numeric model input over a reviewed interval. | Fixed model inputs + min/max/step → deterministic table/curve and optional mathematical local derivative. | BR-CORTE registered Eq. 2.6; new P4 sweep contract. | Out-of-domain, non-divisible step, excessive points, non-finite calculation. | Independently sourced vector, range/boundary tests, UI review-confirm-run E2E. | Equation sensitivity is not a causal effect, probability, or prediction interval. | READY |
| PRD-003 | Compare conditional supplement quantity and cost. | User-entered supplement DM price/currency, count, days, levels → transparent multiplication and deltas. | P3-004 existing contract. | Missing/mismatched price/currency or overflow. | Existing contract and scenario tests. | No invented prices, total ration cost, profit, ROI, or production response. | DONE — reused |
| PRD-004 | Distinguish examples from user-supplied values. | Empty input or explicit example selection → reviewed form values with provenance. | Scenario lab forms and intent parser. | Missing required input is shown before review. | Browser E2E for blank initial state and explicit example selection. | Example/default is not observation or user data. | READY |
| PRD-005 | Ask grounded questions about model, applicability, results and provenance. | Local registered result/metadata → bounded explanation/draft. | P3-007 provider budget gate for remote AI; local deterministic tool path may proceed. | Unknown tool, unsupported model or no result: fail closed. | Allowlist/schema tests and explicit confirmation. | No generated outcomes or behavior control. | BLOCKED for remote LLM; local tools reuse pending audit |
| PRD-006 | Export and reproduce reviewed scientific sensitivity runs. | Versioned request + model version/hash → result and deterministic replay check. | Existing scientific registry and archive contracts. | Version unavailable, tampering, mismatch. | Hash/tamper/replay tests. | Does not upgrade model evidence status. | BACKLOG |
| PRD-007 | Prepare interviews and collect structured product feedback. | Demonstration + interview record → anonymized discovery findings. | Human participants and consent. | No responses means no validation claim. | Protocol and blank feedback template; no invented responses. | Product demand evidence does not validate science. | READY |
