# Population workspace

Grid cell identity is `animal.id`, never spatial position. Layout order is stable by selected deterministic sort; filters narrow activity or scenario delta. Indicator colors are mapped from actual checkpoint values and show a quantitative legend with units. Checkpoints are only those returned in compact observation payload; slider cannot claim unsupported hourly interpolation. Current page renders at most 1,200 cells and “Show more” expands the rendered subset. Individual inspector exposes checkpoint values, paired delta, energy/thirst indices, action, patch index and final bounded transition history/reasons. Histories are not full physiology traces. Aggregates include mean weight, consumption, pasture, illustrative cost, action counts and daily trend; source aggregates only. CSV/JSON/history integration can be expanded in future tasks; first slice supports existing local replay and JSON result export.
