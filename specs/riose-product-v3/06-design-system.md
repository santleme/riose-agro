# Design system

Reuse Product V2 editorial visual language, keyboard/accessibility behavior, responsive breakpoints, reduced motion and component tokens. V3 adds a compact named-scenario comparison strip, sensitivity controls and explicit provenance badges. Keep calculation type visible: **Illustrative engine** or **Published equation**. Use neutral data colors; never imply confidence or biological severity through color. Prefer concise units and tabular numeric figures. Avoid a dashboard redesign unrelated to scenario comprehension.

Scenario review announces its explicit state in a live status: confirmation required, running approved inputs, completed/reproducible, cancelled/no partial output, or rejected/error. Editing a prompt or form hides stale review and requires a new review. Worker progress is not used as a substitute for confirmation. Keep keyboard grid selection and the reduced-motion media query active through these state refinements.
