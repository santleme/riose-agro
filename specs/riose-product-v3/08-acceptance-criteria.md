# Acceptance criteria

- V3 scenario set supports at least three named arms, stable IDs, one shared snapshot/seed, a common declared intervention factor and deterministic replay.
- Sensitivity view shows all tested values, base, units, output and exact arithmetic delta; no confidence interval or causal language.
- BR-CORTE calculator uses the registered Eq. 2.6 implementation and source, requires supplied ADG, enforces/labels domain, exposes only DMI and optional cost from explicit price inputs.
- FarmEngine results remain conspicuously illustrative and are not merged with BR-CORTE outputs.
- Cancel does not write complete history/export artifacts; rerun starts from the reviewed snapshot.
- Population view preserves identities, represents only computed individual outputs and meets measured browser performance limits.
- AI plans require review/confirmation and explanations use retrieved registered result fields; no invented metrics.
- A language-derived experiment records its source question, deterministic validated intent, explicit assumptions, confirmed manifest digest, Worker-echoed executed manifest digest, seed, executor/engine version, units and result digest. Reopening only prepares review; execution requires a new explicit confirmation, and recalculated outputs must canonically match the archive before display.
- Ambiguous counts/durations, implicit wet/as-fed versus dry-matter units, conflicting environmental values, unsupported outcomes or a second changing factor fail closed. Prompt or structured-input edits revoke the current review and never dispatch a Worker.
- Existing Product V2, `experiments.html`, persisted contracts, tests and JS/Rust/WASM parity continue working.
- Paid customer readiness remains blocked until LAB-007 evidence review is complete.
