# Product V3 requirements

Shared interface and accessibility rules remain in Product V2 specs; this file records V3 deltas.

| ID | User-visible behavior | Inputs → outputs | Dependencies | Failure states | Acceptance | Scientific constraint | Status |
|---|---|---|---|---|---|---|---|
| LAB-001 | User configures one baseline and at least two alternatives and compares 3+ scenarios. | Initial snapshot, seed, horizon, one declared factor, scenario configs → named result arms. | P3-002 multi-scenario contract; P3-003 Worker/UI. | Invalid/duplicate arms, unsupported factor, engine error, incompatible saved version. | Contract rejects invalid sets and replay reproduces all arms from the stored snapshot and seed. | FarmEngine arms remain illustrative and carry `validated:false`. | DONE |
| LAB-002 | User adjusts model-supported parameters and sees their values, units and allowed ranges. | BW, supplied ADG, supplement, animal count, optional price assumptions → explicit inputs and result provenance. | P3-004 BR-CORTE module. | Missing/ambiguous input, outside-domain input, non-positive output. | Values are validated before execution and no defaults are silently presented as observations. | BR-CORTE Eq. 2.6 predicts DMI only; ADG remains an input. | READY |
| LAB-003 | User runs reproducible one-factor sensitivity across 3+ values and can inspect the base case. | Frozen inputs, factor grid, seed/version where relevant → ordered output/delta table and visualization. | LAB-001; LAB-002. | Out-of-domain point, changed hidden inputs, non-finite output. | Same input yields byte-equivalent numeric results; each point identifies its changed input and units. | Deterministic sensitivity is not uncertainty, causal effect, or prediction interval. | DONE (FarmEngine supplementation sweep only; scientific sensitivity remains in LAB-002 integration) |
| LAB-004 | User can cancel a long scenario set and rerun from the same reviewed manifest. | Running manifest → explicit cancellation status. | P2-009 Worker lifecycle. | Worker termination/error; partial output. | Cancel never creates a completed history record or replayable partial result. | Cancellation does not imply partial scientific output is usable. | DONE |
| LAB-005 | User explores population observations without DOM/payload growth becoming unbounded. | Animal count, checkpoints, selected metric → paged/virtualized view. | P2-007 native observation parity; P2-008 browser profile. | Unsupported native executor, transfer/memory limit. | Benchmarks at 100/1,000/10,000 animals document browser, time, memory, payload and interaction latency. | Do not invent within-herd variation or individual measurements. | BACKLOG |
| LAB-006 | AI turns a question into a reviewable plan and explains executed results from registered tools. | Bounded prompt + validated run → structured plan/explanation with citations/provenance. | Existing Product/behavior assistant, server-only provider adapters and spend gate. | No provider, invalid output, budget exhausted, prompt injection, unsupported request. | No unvalidated fields execute; no output metric can originate from LLM text. | LLM never controls animal ticks or supplies predictions. | BACKLOG |
| LAB-007 | Operator can show evidence that one quantitative feature is defensible in a narrow domain before paid customer use. | Frozen model version/domain/protocol + independent review/data → go/no-go record. | LAB-002 and scientific evidence. | Insufficient domain fit/independent evidence. | Explicit checklist and signed review artifact; failure keeps paid deployment gated. | Software tests and table reproduction alone are not biological validation. | BACKLOG |
| LAB-008 | A natural-language request stays bound to the reviewed, confirmed, executed and replayed experiment. | Source prompt + clarification + validated intent + approved manifest → bound Worker result and verifiable archive. | P3-009 intent parser; P3-010 digest-bound Worker and archive contract. | Ambiguous inputs, user edits, mismatched Worker result, tampered archive or divergent replay. | Fail closed; do not run after edits without a new review; replay reproduces archived values canonically. | Prompt text is a user question, not a scientific hypothesis or source of output values. | DONE (P3-010) |
