This is conservative coverage bookkeeping and must not be described as source-declared video sessions. Preserve Mountain local wall-clock timestamps without UTC conversion because source rows lack offsets/fold metadata.
- **ADR-BEH-009 (2026-10-15):** Freeze a four-animal confirmatory set before any new sequence score; baseline development uses only five breed-balanced grouped folds among the other 20 animals. Reserve confirmatory results until candidate implementation and selection thresholds are frozen. Baseline protocols use no outcomes to tune model parameters.

- **ADR-BEH-012 (2026-10-15):** The BEH-005 LLM may propose only a closed set of read-only evidence/model/draft/validation tools. The server dispatches locally; it does not pass retrieved evidence back to the provider, accept free-form scientific answers, or expose execution as an LLM tool. Confirmed behavior execution remains blocked by the Perea NO-GO.

Daypart cannot be evaluated without complete 24-hour support; hierarchical models would still have only the same small, confounded source; censor-aware fitting cannot remove carry-forward/observation-process ambiguity; and no direct pasture management intervention outcomes support a hybrid causal effect. Keep NO-GO and prioritize accessible independent observations/rights plus evaluation infrastructure.

A component status/evidence record cannot be inferred from another component's status. The JSON Schema/custom consistency tests are engineering checks only; FarmEngine remains unchanged.

Request stable pseudonymous identities, transition timestamps/durations, observation windows/censoring, annotation and missingness rules, and aligned pasture/management context; obtain explicit commercial/derivative rights before receipt or use.
