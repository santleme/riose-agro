# Open biomass dataset candidate audit

Checked 2026-10-13 using the public repository pages and APIs. No model was fit. The Dryad record's 115,041-byte archive was inspected in memory to verify the workbook schema. Zenodo image archives were not downloaded; only record metadata and HTTP HEAD responses were checked.

## Dryad — mob and rotational grazing

- DOI and primary record: [Dryad 10.5061/dryad.79cnp5ht4](https://datadryad.org/dataset/doi:10.5061/dryad.79cnp5ht4); [Dryad public dataset API](https://datadryad.org/api/v2/datasets/doi%3A10.5061%2Fdryad.79cnp5ht4).
- API metadata reports `visibility=public`, `curationStatus=Published`, version 6, and [CC0 1.0](https://spdx.org/licenses/CC0-1.0.html). Its file listing reports a 98,007-byte XLSX (SHA-256 `47c2aaf50572c8a46b8ab5e3dccd532d36c67fe04fd0f942c5c4f818d281b03b`) and a 16,584-byte README DOCX (SHA-256 `cf1215c422a74c17bfd48d0a26c46d6647964a44b50b253091edf618a7a0086e`).
- Public download check: the unauthenticated version ZIP endpoint [returned HTTP 200](https://datadryad.org/api/v2/versions/173784/download), 115,041 bytes. It contained those two listed files. The individual `/api/v2/files/{id}/download` API endpoint returned 401 in this environment, while the published version ZIP endpoint redirected to a signed public file URL and succeeded; no credentials were used.
- Workbook `Per Harvest Biomass` has 640 tabular records with `Julian Day`, `Plot`, `Rep`, `Year`, `Graze`, and `PGFM Kg/ha`. Its README defines PGFM as **pre-grazing forage mass (kg/ha)** and says these are raw data for Figure 4. The series covers years 2015–2018 and Julian days 161/239, with mob and rotational grazing. A separate 320-row `Cumulative Biomass` sheet is a different, cumulative outcome and must not be substituted for per-harvest mass. `Pasture Heights` contains pre/post mean heights at paddock/replicate granularity; it is not a pointwise height table matching every biomass record.
- **Decision: CONDITIONAL, scientifically suitable for an independent external biomass evaluation after the aggregation key and measurement protocol are mapped.** This is a public CC0 source, in a separate U.S. pasture system and four years, with directly reported dry forage mass in kg/ha. It is distinct from Mendeley's Brazilian cut-quadrat observations but the estimand is closely related. Keep its records as an external cohort; do not pool them. Preserve plot, replicate/paddock, treatment, year and harvest date. Do not treat 640 records as 640 independent experimental units. Before joining height, document that the coarser paddock/replicate mean is the intended prediction-time predictor and aggregate biomass to a compatible level. It is forage biomass, not cattle DMI or ADG.

## Zenodo — Irish Grass Clover

- DOI and primary record: [Zenodo 10.5281/zenodo.14191859](https://zenodo.org/records/14191859); [public Zenodo record API](https://zenodo.org/api/records/14191859?prettyprint=1); creator data catalog: [Teagasc Open Data](https://opendata.teagasc.ie/dataset/irish-grass-clover-dataset-vistamilk).
- Zenodo API reports `access_right=open` and metadata license `cc-by-4.0`. The record's included README states **CC BY-NC-SA 4.0**, and Teagasc's catalog also lists **CC BY-NC-SA 4.0**. These permissions conflict. Apply the more restrictive terms unless the publisher clarifies the record itself: the files are downloadable, but commercial use (including commercial training or evaluation) is not cleared; the NC-SA condition also applies to adaptations.
- The API lists five image archives plus a README (about 10.25 GB total). HTTP HEAD returned 200 for `camera.zip` (1,000,094,312 bytes) and `README.txt` (7,906 bytes); no archive bytes were downloaded. The record description says 2020 camera/phone images include labeled 0.5 × 0.5 m quadrats harvested just after imaging, dried, and labeled with total dry herbage mass (kg DM/ha), composition and post-cut height. Phone views at the same quadrats share the camera GT and are not independent observations. The 2021 drone subset has paddock-level mass and includes visual estimates plus strip-cut estimates, so it is a separate target/granularity cohort.
- **Decision: CONDITIONALLY strong for non-commercial external image-based biomass evaluation; INELIGIBLE for the commercial-use training/evaluation path while the NC-SA conflict remains.** Its 0.25 m² camera quadrats and dried-mass kg DM/ha label are close to Mendeley's 0.25 m² clipped-sample target and provide an independently collected Irish farm domain. For any permitted non-commercial analysis, keep camera/phone duplicates grouped by physical quadrat; keep the drone labels in a separate paddock-level cohort and distinguish visual from cut-strip ground truth. Do not use it to validate DMI, ADG or pasture inventory.

## Pre-fit spatial-CV feasibility

The feature-only feasibility check is in [buffered-cv-feasibility-2026-10.md](buffered-cv-feasibility-2026-10.md), with its reproducible script and JSON. It projects only campaign, farm/field/pixel/point IDs, sward height and coordinates from the processed Parquet; target columns and OOF predictions are never read. Under leave-one-out on field components joined by exact-coordinate aliases and a fixed 100 m training buffer, 13 blocks remain, all 234 height-complete rows are structurally scoreable, and each fold retains 210–216 training rows (105–108 unique coordinates). Thus the ≥70% coverage and ≥4-block gates are structurally attainable. This is not model performance or proof of independence; all 13 blocks sit within the same two farms.
